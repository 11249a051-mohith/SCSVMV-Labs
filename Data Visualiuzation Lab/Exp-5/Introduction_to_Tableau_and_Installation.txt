##Introduction to Tableau and Installation

## Aim:

To study Tableau in detail, understand its features, products, interface, data concepts, and visualization workflow, and install Tableau Public for creating interactive visualizations.

## Introduction to Tableau:

Tableau is a visual analytics and business intelligence platform used to connect, analyze, explore, and present data through interactive visualizations. It helps transform raw data into meaningful charts, graphs, maps, dashboards, and stories.

Tableau mainly focuses on visual analysis. Instead of writing lengthy programs to create graphs, users can select data fields and drag them into different areas of the workspace. Tableau automatically generates visualizations based on the selected dimensions, measures, and chart types.

Tableau supports the complete data analysis process, including connecting to data sources, preparing data, creating worksheets, applying filters, designing dashboards, and presenting findings through stories. It is widely used in business, education, finance, marketing, human resources, and other fields.

## Objectives of Using Tableau:

- To convert raw data into meaningful visual information.
- To explore datasets interactively.
- To identify trends, patterns, and relationships.
- To compare categories and numerical values.
- To analyze geographical data.
- To create dashboards containing multiple visualizations.
- To present analytical findings in a structured manner.

## Important Tableau Products:

1.Tableau Desktop: Used to connect to data, create worksheets, build dashboards, and perform detailed analysis.
2.Tableau Public: A free platform for creating and publicly sharing visualizations. It is useful for students and learning purposes.
3.Tableau Server: Used by organizations to publish, manage, and share Tableau content.
4.Tableau Cloud: A hosted platform for publishing and collaborating on Tableau content online.
5.Tableau Prep: Used to clean, combine, and reshape data before visualization.

## Main Features of Tableau:

## Tableau Data Concepts
1.Dimensions:
Dimensions are descriptive fields used to classify data into categories or groups. Examples include Product, Category, Region, City, Department, and Customer.

2.Measures:
Measures are generally numerical fields that can be summarized or aggregated. Examples include Sales, Profit, Quantity, Cost, and Salary. Common aggregation functions include SUM, AVG, MIN, MAX, and COUNT.

3.Discrete Fields:
Discrete fields represent separate values or categories. They are useful for displaying distinct items such as regions, cities, and product categories.

4.Continuous Fields:
Continuous fields represent a range of values and generally create an axis. They are useful for showing numerical trends, distributions, and relationships.

5.Data Types:
Tableau supports different data types, including text, numbers, dates, date-times, Boolean values, and geographical fields. Selecting the correct data type helps Tableau process and visualize data appropriately.

## Tableau Interface

1.Data Pane:
The Data pane displays the available data sources and fields in a workbook. Fields are generally organized into dimensions and measures.

2.Rows Shelf:
The Rows shelf controls the vertical arrangement of a visualization. Placing a field here can create an axis or row headers.

3.Columns Shelf:
The Columns shelf controls the horizontal arrangement of a visualization. It can display category headers or numerical axes depending on the selected field.

4.Marks Card:
The Marks card controls the appearance of visual elements. It includes options such as Color, Size, Label, Detail, Tooltip, and Shape.

5.Filters Shelf:
The Filters shelf restricts the data displayed in a visualization. Filters can be applied to dimensions, measures, and dates.

6.Pages Shelf:
The Pages shelf displays different subsets of data progressively. It is useful for examining changes across time periods or categories.

7.Show Me:
Show Me provides a selection of chart types based on the fields chosen by the user. It helps beginners select suitable visualizations.

8.Worksheet:
A worksheet is an individual analytical view, such as a bar chart, line chart, map, or scatter plot.

9.Dashboard:
A dashboard combines multiple worksheets into a single view. It may include charts, filters, legends, text, and other interactive elements.

10.Story:

A story is a sequence of worksheets or dashboards arranged to communicate analytical findings step by step.

## Tableau Data Sources:

Tableau supports connections to several types of data sources, including:
- Excel files.
- CSV and text files.
- Relational databases.
- Cloud data sources.
- Published data sources.
- Other supported enterprise and analytical systems.

After connecting to a data source, users can examine field names, data types, and sample values. Data preparation may involve renaming fields, changing data types, filtering records, combining tables, creating calculations, and removing unwanted data.

## Types of Tableau Visualizations:

1.Bar Chart:
A bar chart compares values across categories. It can be used to compare sales by product, marks by subject, or quantities by region.

2.Line Chart:
A line chart connects data points to show changes over an ordered sequence, especially over time. It is useful for displaying monthly sales and yearly growth.

3.Pie Chart:
A pie chart divides a circle into sectors to represent proportions of a whole. It is most suitable when the number of categories is small.

4.Scatter Plot:
A scatter plot represents pairs of numerical values as points. It helps analyze relationships between variables, such as sales and quantity or study hours and marks.

5.Maps:
Maps display geographical information and help compare values across cities, states, countries, and other geographic regions.

6.Heat Map:
A heat map uses color intensity to represent values. It helps identify high and low values across a matrix-like arrangement.

7.Treemap:
A treemap represents hierarchical or part-to-whole data using nested rectangles. Rectangle size and color can represent different measures.

8.Histogram:
A histogram groups numerical data into intervals and displays their frequencies. It is useful for understanding data distributions.

9.Filters and Interactivity:

Filters allow users to display selected portions of a dataset based on categories, regions, dates, customers, or other fields. Filters can also be applied across multiple worksheets in a dashboard.

Tooltips display additional information when the pointer moves over a visual element. Highlighting helps users focus on selected categories, while parameters allow interactive changes to values or analytical options.

## Calculated Fields:

Calculated fields are used to create new values from existing data by applying expressions. They can be used to calculate profit ratios, growth percentages, classifications, and other analytical measures.

## Dashboards:

A dashboard combines multiple worksheets into one screen to provide a consolidated view of important information.

A typical dashboard may contain:

- KPI or summary values.
- Bar charts.
- Line charts.
- Maps.
- Filters.
- Legends.
- Text descriptions.

A good dashboard should have a clear objective, organized layout, readable labels, and consistent formatting. Unnecessary charts and decorative elements should be avoided.

## Stories:

Tableau Stories present analytical findings in a logical sequence. For example, a story can display overall sales first, compare product categories next, analyze regional performance, and then show relationships between numerical variables. Captions can be included to explain the findings at each stage.
