# Experiment 6: Data Aggregation and Statistical Functions in Tableau

## Aim
To calculate summary statistics and category-level totals for a sales dataset.

## Theory
Aggregation combines many records into meaningful summaries. Common measures include total, average, minimum, and maximum. Grouping by a dimension such as Category allows comparison between segments. Tableau performs these calculations interactively when a measure is placed in a view; the companion program demonstrates the same logic reproducibly.

## Algorithm
1. Load the prepared sales dataset.
2. Calculate total, average, minimum, and maximum Sales.
3. Group Sales by Category.
4. Display the summaries.
5. Recreate the same summaries in Tableau using measure aggregations.

## Result
Overall and category-level sales statistics were calculated successfully.
